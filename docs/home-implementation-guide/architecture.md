# Архитектура

Источник истины: `docs/IMPLEMENTATION_PLAN.md`.

- один Laravel route и один типизированный контракт страницы;
- desktop и mobile используют общие domain-компоненты;
- page компонует, controller координирует, DTO сериализует;
- presentation-компоненты не зависят от Eloquent;
- файлы компонентов используют snake_case и не превышают 300 строк;
- Vercel preview не дублирует UI.

Если требование меняет план, обновите план или зафиксируйте решение в ADR.
