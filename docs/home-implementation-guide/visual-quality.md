# Визуальное качество

Источники: `home-reference/README.md`, `home-reference/mobile/README.md` и
`docs/QUALITY_GATES.md`.

Контрольные viewport:

- desktop `1440 × 889`, node `1:15`;
- mobile `390 × 1139`, node `18:967`.

PNG и SVG определяют внешний вид, JSON — точные свойства. Сначала проверяется
геометрия крупных блоков, затем overlay и raster diff. Структурное расхождение
блокирует приёмку даже при допустимом общем проценте пикселей.

Перед снимком дождитесь шрифтов и изображений, отключите motion, используйте
фиксированные fixture, DPR и версию браузера. После совпадения контрольных
viewport проверьте промежуточные ширины и доступность.
