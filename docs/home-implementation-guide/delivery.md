# Поставка

Перед поставкой прочитайте `AGENTS.md`, `docs/ROADMAP.md` и
`docs/QUALITY_GATES.md`.

Перед каждым push:

1. определить базу: `staging`, иначе `main`;
2. получить актуальную базу с origin;
3. влить базу в feature-ветку и разрешить конфликты;
4. выполнить полный gate;
5. сразу отправить ветку; если база сдвинулась — повторить цикл.

Не сливайте PR самостоятельно. Итоговая передача содержит ветку, SHA, GitHub branch URL,
GitHub Pages URL, результаты тестов и разделы `Что и зачем`, `Как`, `Риски`,
`Как протестировано`.
